Discord Bio Builder with Limit Counter (discord_bio.py)

Coded by: Muse Spark (Meta AI assistant)

WHAT IT DOES:
Builds an About-Me bio while counting characters the way Discord does (UTF-16 code units, 256 max) and warns when over.

REQUIREMENTS:
Python 3.8+ only - no extra packages needed (stdlib only).

HOW TO RUN:
python discord_bio.py --help
python discord_bio.py --text "First line" --text "Second line"

PLATFORM:
Windows + Linux + Mac: yes.
